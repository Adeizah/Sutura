# Sutura by Basmah Website

A responsive three-section landing website for Sutura by Basmah, with service discovery and direct WhatsApp enquiry links.

## Important before publishing
- The WhatsApp link currently uses the normalized number `2347068062213`, based on the contact number shown on the supplied flyer. Please test it and confirm it opens Basmah's WhatsApp before publishing.
- The photos are illustrative stock photography loaded from Unsplash image URLs. They are not represented as Basmah's own work. Review the current image URLs and their licence/availability before launch; replace with actual portfolio photos as soon as possible.
- No booking form or appointment database is used. Customers message Basmah directly on WhatsApp.
- The site is static and can be hosted on GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — layout and visual styling
- `script.js` — mobile navigation and current year

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open repository Settings → Pages.
4. Select deployment from the `main` branch and `/ (root)`.
5. Save and wait for the Pages URL to become available.
